# Projek_PCD_Kelompok-7
Sistem identifikasi penyakit daun otomatis berbasis pengolahan citra digital menggunakan ekstraksi fitur handcrafted (Color Moments, HSV Histogram, GLCM, LBP) dan klasifikasi SVM kernel RBF. Mencapai akurasi 96.67% pada dataset Roboflow 2.501 citra tanpa deep learning. | RAPIDS Journal — S1 Sains Data UNESA 2026
